Captured the deployment assessment as a task node so it stops living in a
transcript. Written as a scorecard plus six phases, each with an **exit test** —
"a node restarts and keeps its stake", not "improve persistence" — because a
roadmap whose steps are nouns can be declared done by writing about them.

Re-grounded the state before writing it down. `CLAUDE.md` is flagged in-repo as
predating the RNS/shielded/prover work, so every row came from greps:

- **No transaction ingress.** No HTTP/RPC server anywhere; `rest_api_version` is
  vestigial and there is no client binary. A client must build `Message::signed`
  and send to a sentinel rhash. This is the dominant gap: without it, capacity is
  unknowable and every later phase is unmeasurable.
- **Stake is in-memory.** `StakeStore` is a `DashMap` in
  `committer/src/epoch_manager.rs`; nothing writes it. Meanwhile the data service
  *does* persist a state file — so chain state survives a restart and the
  validator set does not. That asymmetry will present as a cluster that "comes
  back wrong", which is the kind of failure that eats a day per occurrence.
- **`slash_fraction` has no enforcement site** — it appears only where `CostModel`
  is constructed. A parameter that nothing reads is not a security model.
- `StubStakingManager`/`StubEpochReconciler` still ship in core; the committer
  replaced the staking stub with a real manager and has a reconcile handler, so
  the honest statement is "epoch behavior under traffic is unverified", not
  "epochs are stubbed".

Two sequencing judgements recorded deliberately:

1. **Transport across real hosts is Phase 2, not an afterthought.** Dense mesh has
   never run off loopback, and if it fails the network shape changes — relay, or
   fewer validators, or gateway placement elsewhere — which re-plans everything
   downstream. A plan that defers it to the end discovers the constraint after
   building to it.
2. **Gateways belong inside the topology.** A gateway reaches sentinels over the
   same leaf links as any other node, so it consumes interfaces. If gateway count
   isn't in the generator's plan, it silently changes the mesh.

The first concrete action is written into the node and needs nothing new built:
`--validators 4 --addresses-file <provisioner output>`, one data-service sidecar
per host seeded from the same genesis, the shared UDP range opened between members
only, and the `peered_topology_e2e` assertions ported to real hosts.
