# Proving happens client-side

Roadmap key decision: shielded proof generation is a **client** responsibility. A shielded transaction carries a completed halo2 proof; worker nodes (finalizer/committer) only run the millisecond-scale verification path. This keeps worker CPU/memory budgets independent of proving cost, and means proving hardware (or slow proving on commodity CPUs) stays client-owned.

Consequence enforced in the repo: live-prove tests are gated behind `#[ignore]` (core: 5, prover: 1, sentinel: 1, rns_live: 1) — they are benchmark-only, never part of the normal test baseline.
